# 状態異常 詳細設計書

## 1. 目的

本設計書では、戦闘参加者に付与される状態異常について、状態の保持、効果発生タイミング、効果終了条件、およびターンとの連携方法を定義する。

現時点では以下の状態異常を対象とする。

- 毒
- 麻痺

状態異常を発生させる具体的な攻撃や魔法については、本設計の対象外とする。

## 2. 状態異常の基本方針

状態異常は戦闘参加者に付与される一時的な戦闘状態とする。

状態異常そのものは個体識別を必要としないため、IDを持たない。

状態異常の種類および状態を構成する値によって同一性を判断する。

状態異常は戦闘参加者Entityが保持する。

Turnは状態異常そのものを所有せず、必要なタイミングで戦闘参加者の状態異常を確認する。

## 3. 状態異常種別

以下の状態異常種別を定義する。

```text
Poison
Paralysis
```

概念上は以下とする。

```csharp
public enum StatusEffectType
{
    Poison,
    Paralysis
}
```

## 4. 複数状態異常

1人の戦闘参加者が複数種類の状態異常を同時に保持することを許可する。

したがって、

```text
毒
+
麻痺
```

を同時に保持できる。

同一種類の状態異常を複数個同時に保持することはしない。

例えば、

```text
毒
毒
毒
```

という状態にはしない。

戦闘参加者について、

```text
毒である
または
毒ではない
```

のどちらかとして扱う。

## 5. 毒

毒は、ターン終了時に継続的なHPダメージを与える状態異常とする。

毒状態であっても通常の行動を妨げない。

## 6. 毒ダメージ

毒状態の戦闘参加者は、各ターン終了時に10のダメージを受ける。

```text
PoisonDamage = 10
```

毒ダメージは固定値とする。

以下の能力値によって変化しない。

- 攻撃力
- 守備力
- すばやさ
- 装備

## 7. 毒ダメージの発生タイミング

毒ダメージは通常行動がすべて終了した後に適用する。

基本的な流れは以下とする。

```text
通常行動終了
↓
ターン終了処理
↓
毒状態確認
↓
毒ダメージ
↓
死亡確認
↓
戦闘終了確認
```

Turnの状態としては、

```text
Ending
```

の間に処理する。

## 8. 毒状態での行動

毒状態であっても行動そのものは制限しない。

例えば毒状態でも以下を実行できる。

```text
攻撃
防御
魔法
アイテム
逃げる
```

他の状態異常によって行動不能となっている場合は、その状態異常のルールを優先する。

## 9. 毒による死亡

毒ダメージによってHPが0になった場合、通常のダメージと同様に死亡する。

例：

```text
現在HP = 8
毒ダメージ = 10
```

の場合、

```text
HP = 0
死亡
```

となる。

HPを負数にはしない。

HP下限の保証はBattleParticipant側の責務とする。

## 10. 死亡者への毒処理

すでに死亡している戦闘参加者について、毒ダメージ処理は実行しない。

```text
HP = 0
```

である場合、その後の毒効果は処理しない。

## 11. 毒と防御

毒ダメージには防御状態を適用しない。

防御している場合でも、

```text
Damage = 10
```

とする。

## 12. 毒と守備力

毒ダメージは守備力によって軽減しない。

```text
守備力 0
```

であっても、

```text
守備力 999
```

であっても毒ダメージは10とする。

## 13. 毒と装備

現時点では、装備による毒耐性や毒無効化を設けない。

そのため装備状態に関係なく毒効果を適用する。

## 14. 麻痺

麻痺は、戦闘参加者の行動機会を失わせる状態異常とする。

麻痺状態では、自身の行動順が到来したときに選択済みの行動を実行できない。

## 15. 麻痺による行動消費

麻痺状態の戦闘参加者に行動順が到来した場合、その行動を実行せず、1回分の行動を消費する。

概念上、

```text
ActionConsumed = true
ConsumedReason = Paralyzed
```

とする。

攻撃、魔法などの選択内容に関係なく行動は実行しない。

## 16. 麻痺時のMP

麻痺によって魔法を実行できなかった場合、MPは消費しない。

例：

```text
選択行動 = ホイミ
麻痺状態 = true
```

の場合、

```text
ホイミ発動なし
MP消費なし
行動消費あり
```

とする。

## 17. 麻痺時の攻撃

麻痺によって通常攻撃を実行できなかった場合、命中判定は行わない。

```text
攻撃判定なし
ダメージなし
行動消費あり
```

とする。

## 18. 麻痺の有効回数

麻痺は3回分の行動機会を失わせる。

麻痺状態には残り回数を持たせる。

麻痺付与時は、

```text
RemainingCount = 3
```

とする。

## 19. 麻痺回数の減少

麻痺によって実際に行動機会を失った場合にのみ残り回数を1減少させる。

```text
RemainingCount
3
↓
2
↓
1
↓
0
```

RemainingCountが0になった時点で麻痺状態を解除する。

## 20. 麻痺解除タイミング

3回目の行動不能が発生した直後に麻痺を解除する。

例：

```text
RemainingCount = 1
```

の戦闘参加者に行動順が到来した場合、

```text
行動できない
↓
RemainingCount = 0
↓
麻痺解除
```

となる。

その行動については、麻痺が解除されても実行できない。

次のターンから通常行動可能となる。

## 21. 麻痺中のターン参加

麻痺状態でもターン参加者から除外しない。

すばやさによる行動順も通常どおり決定する。

例えば、

```text
勇者
Speed = 50
Paralysis = true
```

の場合でも、すばやさ50として行動順を決定する。

自身の順番が到来した時点で麻痺判定を行う。

## 22. 麻痺中の行動選択

麻痺状態であっても、ターン開始時には通常どおり行動を選択する。

その後、自身の行動順で麻痺が有効であれば行動を失う。

したがって、

```text
ターン開始
↓
ホイミを選択
↓
行動順到来
↓
麻痺判定
↓
行動失敗
```

という処理を許可する。

## 23. 麻痺と死亡

麻痺状態であってもHPが0になった場合は死亡する。

死亡した場合、その後の麻痺残り回数を消費する必要はない。

死亡状態が行動不能判定として優先される。

## 24. 行動不能判定の優先順位

戦闘参加者の行動順が到来した場合、以下の順番で状態を確認する。

```text
1. 死亡しているか
2. 麻痺しているか
3. 通常行動を実行
```

### 死亡

死亡している場合、

```text
ConsumedReason = DeadBeforeAction
```

とする。

麻痺回数は減少させない。

### 麻痺

生存しており麻痺している場合、

```text
ConsumedReason = Paralyzed
```

とする。

麻痺残り回数を1減少させる。

## 25. 毒と麻痺の同時保持

毒と麻痺を同時に保持している場合、それぞれ独立して効果を適用する。

例：

```text
勇者
Poison = true
Paralysis RemainingCount = 2
```

の場合、

行動順では、

```text
麻痺によって行動不能
RemainingCount 2 → 1
```

となる。

ターン終了時には、

```text
毒ダメージ 10
```

を受ける。

## 26. 状態異常の保持

BattleParticipantは状態異常を保持する。

概念上は以下とする。

```text
BattleParticipant
 └ StatusEffects
      ├ Poison
      └ Paralysis
```

状態異常そのものはBattleParticipantとは別の値として扱う。

## 27. Poison Value Object

毒は状態として追加値を必要としない。

概念上、

```text
Poison
```

という状態だけで表現できる。

毒ダメージ10については毒のルールとして定義する。

概念モデルとしては、

```csharp
public sealed record PoisonStatus;
```

のようなValue Objectとして扱える。

ただし具体的な実装方式は全体構成に合わせて決定する。

## 28. Paralysis Value Object

麻痺は残り行動不能回数を保持する必要がある。

概念上、

```text
Paralysis
 └ RemainingCount
```

とする。

生成時は、

```text
RemainingCount = 3
```

とする。

RemainingCountが0以下の麻痺状態は存在させない。

0になった時点で麻痺そのものをBattleParticipantから除去する。

## 29. 麻痺の不変条件

Paralysisは保持されている間、以下を満たす。

```text
RemainingCount >= 1
```

かつ、

```text
RemainingCount <= 3
```

とする。

```text
RemainingCount = 0
```

のParalysisを保持してはならない。

## 30. 麻痺状態の更新

状態異常はValue Objectとして扱うため、RemainingCountを内部的に書き換えるのではなく、新しい値へ置き換える方式を基本とする。

概念上、

```text
Paralysis(3)
↓
Paralysis(2)
↓
Paralysis(1)
↓
状態なし
```

とする。

## 31. 状態異常付与

状態異常を付与する場合、BattleParticipantに対して状態異常付与を要求する。

概念上、

```csharp
participant.ApplyStatusEffect(...);
```

とする。

外部処理がBattleParticipant内部の状態異常コレクションを直接変更しない。

## 32. 状態異常解除

状態異常を解除する場合もBattleParticipantを通して行う。

概念上、

```csharp
participant.RemoveStatusEffect(...);
```

とする。

状態異常保持情報を外部から直接書き換えない。

## 33. 状態異常の重複付与

同じ種類の状態異常がすでに存在する状態で、同じ状態異常を再度付与した場合の扱いは現時点では未確定とする。

例えば、

```text
麻痺 RemainingCount = 1
```

の状態で、再度麻痺を受けた場合、

```text
3へ戻す
現在値を維持する
加算する
```

のどれとするかは別途決定する。

毒についても、すでに毒状態で再度毒を受けた場合の扱いを別途定義する。

## 34. 状態異常の発生判定

毒または麻痺になる確率は本設計では定義しない。

例えば、

```text
20%で毒
10%で麻痺
```

のような確率判定は、状態異常を付与する攻撃・魔法・行動側の詳細設計で定義する。

状態異常自身は、

```text
付与された後どう振る舞うか
```

を担当する。

## 35. 毒の解除

現時点では毒の解除条件が確定していない。

そのため、以下は未定義事項とする。

```text
一定ターンで自然回復するか
戦闘終了まで継続するか
アイテムで解除できるか
魔法で解除できるか
```

解除条件が決定するまでは、Poisonは明示的に解除されるまで保持される状態として扱う。

## 36. 戦闘終了時の状態異常

戦闘終了時に状態異常を保持するかどうかについては、本設計では確定しない。

BattleParticipantが戦闘専用Entityである場合、戦闘終了とともにBattleParticipant自体が破棄されるため、状態異常も同時に消滅する。

戦闘をまたいで状態を保持するCharacterが存在する場合、その引き継ぎルールはCharacter側で別途定義する。

## 37. Turnとの連携

Turnは以下のタイミングでBattleParticipantの状態異常を確認する。

### 行動時

```text
死亡確認
↓
麻痺確認
↓
行動
```

### ターン終了時

```text
毒確認
↓
毒効果適用
```

Turn自身は、

```text
毒ダメージは10
麻痺は3回
```

という具体的ルールを保持しない。

状態異常側のルールを利用する。

## 38. 状態異常効果結果

状態異常の効果発生結果を値として返せるものとする。

概念上、

```text
StatusEffectResult
 ├ StatusEffectType
 ├ ParticipantId
 ├ Damage
 ├ ActionPrevented
 ├ EffectRemoved
 └ RemainingCount
```

とする。

## 39. 毒効果結果

例：

```text
StatusEffectType = Poison
Damage = 10
ActionPrevented = false
EffectRemoved = false
```

毒によって死亡した場合でもDamageは実際に適用された値を保持する。

例えば現在HPが5だった場合、

```text
Damage = 5
```

としてもよい。

実際のダメージ結果の扱いはBattleParticipantのTakeDamage結果との整合性を取る。

## 40. 麻痺効果結果

例えば残り回数3の状態で麻痺効果が発生した場合、

```text
StatusEffectType = Paralysis
Damage = 0
ActionPrevented = true
RemainingCount = 2
EffectRemoved = false
```

3回目の場合、

```text
RemainingCount = 0
EffectRemoved = true
```

とする。

## 41. C#概念モデル

状態異常種別は概念上以下とする。

```csharp
public enum StatusEffectType
{
    Poison,
    Paralysis
}
```

毒は概念上、

```csharp
public sealed record PoisonStatus;
```

麻痺は概念上、

```csharp
public sealed record ParalysisStatus
{
    public int RemainingCount { get; }
}
```

とする。

実際に共通インターフェースや基底クラスを設けるかは、実装時に必要性を判断する。

## 42. 共通基底を必須としない

毒と麻痺では効果発生タイミングが異なる。

```text
毒
→ ターン終了時

麻痺
→ 行動時
```

また保持するデータも異なる。

そのため、

```csharp
IStatusEffect
```

などの共通抽象化を設けること自体を詳細設計上の必須事項とはしない。

無理に共通化するより、ドメイン上の違いをそのまま表現する。

## 43. 状態異常の責務

状態異常は以下を担当する。

```text
自分がどのような状態異常か
状態異常固有の値
状態異常固有の効果
状態異常の終了判定
```

BattleParticipantは、

```text
どの状態異常を現在保持しているか
```

を管理する。

Turnは、

```text
いつ状態異常を評価するか
```

を管理する。

## 44. 禁止事項

状態異常処理では以下を行わない。

```text
行動順を決定する
```

```text
次のターンを開始する
```

```text
戦闘の勝敗を直接決定する
```

```text
装備を変更する
```

```text
攻撃ダメージを計算する
```

```text
魔法を実行する
```

## 45. テスト観点

### 毒付与

毒状態を保持できる。

毒状態でも通常行動できる。

### 毒ダメージ

ターン終了時に10ダメージを受ける。

通常行動中には毒ダメージが発生しない。

守備力によって毒ダメージが減少しない。

防御状態によって毒ダメージが減少しない。

装備によって毒ダメージが変化しない。

### 毒による死亡

HP10の参加者が毒ダメージを受けてHP0になる。

HP5の場合にHPが負数にならない。

毒によるHP0で死亡状態になる。

### 死亡者

死亡者へ毒ダメージを適用しない。

### 麻痺

麻痺付与時にRemainingCountが3となる。

麻痺状態で行動順が来た場合、行動できない。

行動を1回消費する。

MPを消費しない。

攻撃判定を行わない。

### 麻痺回数

1回目で3から2になる。

2回目で2から1になる。

3回目で1から0になり麻痺が解除される。

3回目の行動自体は実行できない。

次の行動機会から通常行動できる。

### 死亡と麻痺

死亡している場合は麻痺処理を行わない。

死亡によって行動できなかった場合、麻痺残り回数は減少しない。

### 複合状態

毒と麻痺を同時に保持できる。

麻痺によって行動不能となってもターン終了時に毒ダメージを受ける。

## 46. 設計上の確定事項

状態異常について以下を確定する。

```text
状態異常はBattleParticipantが保持する
```

```text
毒と麻痺は同時に存在できる
```

```text
同一種類の状態異常を複数保持しない
```

```text
毒は行動を妨げない
```

```text
毒はターン終了時に10ダメージを与える
```

```text
毒ダメージは守備力を無視する
```

```text
毒ダメージは防御状態を無視する
```

```text
毒によってHP0になれば死亡する
```

```text
麻痺は行動機会を1回消費する
```

```text
麻痺状態でも行動順には含まれる
```

```text
麻痺状態でもターン開始時には行動を選択する
```

```text
麻痺による行動不能ではMPを消費しない
```

```text
麻痺による行動不能を3回経験すると解除される
```

```text
死亡判定を麻痺判定より優先する
```

```text
死亡による行動不能では麻痺残り回数を減少させない
```

## 47. 未確定事項

状態異常について残る未確定事項は以下とする。

```text
毒の解除条件
```

```text
毒を再度付与された場合の扱い
```

```text
麻痺を再度付与された場合の扱い
```

```text
毒を付与する行動と発生確率
```

```text
麻痺を付与する行動と発生確率
```

```text
戦闘終了後に状態異常を引き継ぐか
```

これらは状態異常を発生させる行動や、戦闘参加者・Characterのライフサイクルを設計する際に確定する。
