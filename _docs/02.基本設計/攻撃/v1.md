# 攻撃 詳細設計書

## 1. 目的

本設計書では、通常攻撃に関する処理、命中判定、ダメージ計算、防御との関係、会心の一撃、および攻撃失敗時の扱いを定義する。

ターン管理、戦闘参加者の状態管理、装備補正そのものについては別の詳細設計で定義する。

## 2. 攻撃の責務

通常攻撃は、攻撃者が対象となる戦闘参加者へ物理ダメージを与える行動とする。

攻撃処理は以下を担当する。

- 攻撃者の確認
- 攻撃対象の確認
- 命中判定
- 会心判定
- 防御状態の確認
- ダメージ算出
- 対象へのダメージ適用
- 攻撃結果の生成

攻撃処理自身は以下を担当しない。

- 行動順の決定
- ターンの開始・終了
- 装備品そのものの管理
- 戦闘終了判定
- 状態異常の付与
- 魔法ダメージ
- 回復処理

## 3. 攻撃実行条件

通常攻撃を実行するためには、以下を満たす必要がある。

### 攻撃者

攻撃者が存在すること。

攻撃者が死亡状態ではないこと。

そのターンに攻撃可能な状態であること。

### 攻撃対象

攻撃対象が指定されていること。

攻撃対象が敵対陣営に所属していること。

攻撃実行時点で対象が生存していること。

## 4. 攻撃対象

攻撃対象はターン開始時の行動選択時に決定する。

通常攻撃では1回の攻撃につき1体を対象とする。

複数体への同時攻撃は本設計では扱わない。

## 5. 対象が死亡していた場合

ターン開始時には生存していた対象が、攻撃者の行動順までに死亡している場合がある。

この場合、通常攻撃は失敗とする。

別の対象への自動変更は行わない。

攻撃者の1ターン分の行動は消費する。

攻撃結果は以下とする。

```text
Failed
Reason = TargetDead
```

## 6. 攻撃処理の基本フロー

通常攻撃は以下の順序で処理する。

```text
1. 攻撃者の有効性確認
2. 攻撃対象の有効性確認
3. 命中判定
4. 会心の一撃判定
5. 防御状態確認
6. ダメージ計算
7. ダメージ適用
8. 攻撃結果生成
9. 行動消費
```

命中判定でミスになった場合、それ以降のダメージ処理は行わない。

## 7. 命中判定

通常攻撃実行時に乱数を1回生成する。

乱数は以下の範囲とする。

```text
0.0 ～ 1.0
```

判定値が以下の範囲の場合、攻撃はミスとする。

```text
0.0 ～ 0.1
```

したがって、仕様上のミス確率は約10%とする。

境界値0.1はミスに含む。

例：

```text
0.05 → ミス
0.10 → ミス
0.11 → 命中
```

## 8. ミス時の処理

攻撃がミスした場合、対象へダメージを与えない。

```text
Damage = 0
```

攻撃者の行動は消費する。

攻撃結果は以下とする。

```text
Miss
```

ミスした場合、会心判定および通常ダメージ計算は行わない。

## 9. 通常ダメージ

通常攻撃が命中した場合、以下の式を使用する。

```text
攻撃力 / 2 - 守備力 / 4
```

使用する攻撃力は、攻撃実行時点における攻撃者の最終攻撃力とする。

使用する守備力は、攻撃実行時点における対象の最終守備力とする。

最終攻撃力・最終守備力には装備補正を反映した値を使用する。

## 10. 防御時のダメージ

攻撃対象が防御状態の場合、通常のダメージ式は使用しない。

以下の式を使用する。

```text
攻撃力 / 4 / 2 - 守備力 / 4
```

これは以下と同義とする。

```text
攻撃力 / 8 - 守備力 / 4
```

ただし、実装上どちらの記述を使用するかは統一する。

本設計では要件表現を維持し、

```text
攻撃力 / 4 / 2 - 守備力 / 4
```

を基準式とする。

## 11. 防御判定

防御状態は攻撃を受けた時点で確認する。

対象がそのターンに防御を選択し、防御効果が有効になっている場合のみ防御用ダメージ計算を使用する。

まだ防御行動を実行していない場合は、防御効果を適用しない。

例：

```text
勇者 すばやさ 50
敵   すばやさ 20
```

敵がそのターンに防御を選択していても、勇者より後に行動する場合、勇者の攻撃時点では防御効果は有効ではない。

防御行動を実行した後から、そのターン終了まで防御効果を有効とする。

## 12. ダメージの最低値

通常攻撃および防御時の計算結果が0未満になった場合、最終ダメージを0とする。

```text
Damage < 0
↓
Damage = 0
```

0ダメージを許可する。

最低1ダメージの保証は行わない。

## 13. 小数の扱い

攻撃力および守備力は整数値とする。

除算によって端数が発生した場合、各計算結果は整数へ変換する。

端数は切り捨てとする。

例：

```text
攻撃力 25

25 / 2 = 12
```

```text
守備力 15

15 / 4 = 3
```

したがって、

```text
12 - 3 = 9
```

をダメージとする。

## 14. 会心の一撃

通常攻撃には会心の一撃が発生する可能性を持たせる。

会心の一撃が発生した場合、対象の守備力を無視する。

また、対象が防御状態であっても防御による軽減を適用しない。

つまり会心時には、

```text
守備力
防御状態
```

の双方を無視する。

## 15. 会心ダメージ

現時点では、会心の一撃による具体的なダメージ量は未定義とする。

会心判定の発生確率についても未定義とする。

したがって実装時には以下を別途確定する必要がある。

```text
会心発生確率
会心ダメージ計算式
```

## 16. 会心とミスの優先順位

攻撃処理では命中判定を先に行う。

```text
命中判定
↓
命中した場合のみ会心判定
```

ミスした攻撃が会心になることはない。

処理順序は以下とする。

```text
命中判定
↓
会心判定
↓
ダメージ計算
```

## 17. 乱数生成

命中判定および会心判定で使用する乱数生成処理は、攻撃処理内部で具体的な乱数生成方式に依存しない。

概念上、乱数取得元を外部から利用する。

```csharp
public interface IRandomSource
{
    double NextDouble();
}
```

本番では通常の乱数生成を利用する。

テスト時には固定値を返す実装へ差し替え可能とする。

## 18. ダメージ適用

算出されたダメージを対象へ適用する。

概念上は以下とする。

```csharp
target.TakeDamage(damage);
```

攻撃側が対象のHPを直接変更しない。

HP変更およびHP0時の死亡判定は戦闘参加者Entity側へ委譲する。

## 19. HP下限

攻撃によって対象HPが0未満になることは許可しない。

例：

```text
現在HP 5
ダメージ 20
```

の場合、

```text
HP = 0
```

とする。

負数のHPは保持しない。

この保証はBattleParticipant側の責務とする。

## 20. 攻撃力

ダメージ計算で使用する攻撃力は、攻撃者の最終攻撃力とする。

概念上、

```text
基礎攻撃力
+
武器補正
+
防具補正
+
アクセサリー補正
```

を反映した値を利用する。

Attack処理自身が装備を確認して加算することはしない。

BattleParticipantから取得した最終攻撃力を利用する。

## 21. 守備力

同様に、守備力についても対象の最終守備力を利用する。

概念上、

```text
基礎守備力
+
武器補正
+
防具補正
+
アクセサリー補正
```

を反映済みの値とする。

Attack処理は装備の内容を直接参照しない。

## 22. 攻撃結果

攻撃実行結果を値として返す。

概念的には以下の情報を持つ。

```text
AttackResult
 ├ ResultType
 ├ AttackerId
 ├ TargetId
 ├ Damage
 ├ IsCritical
 └ FailureReason
```

## 23. 攻撃結果種別

以下を定義する。

```text
Hit
Miss
Critical
Failed
```

### Hit

通常攻撃が命中し、通常ダメージ計算を行った。

### Miss

命中判定に失敗した。

### Critical

会心の一撃が発生した。

### Failed

攻撃そのものを実行できなかった。

## 24. 攻撃失敗理由

Failedの場合、以下の理由を識別できるものとする。

```text
AttackerDead
TargetDead
InvalidTarget
```

### AttackerDead

攻撃実行前に攻撃者が死亡している。

### TargetDead

選択した対象がすでに死亡している。

### InvalidTarget

攻撃可能な対象ではない。

## 25. AttackResult

AttackResultは処理結果を表すValue Objectとして扱う。

AttackResult自身がゲーム状態を変更することはない。

例：

```text
ResultType = Hit
AttackerId = Hero
TargetId = SlimeA
Damage = 18
IsCritical = false
```

ミスの場合、

```text
ResultType = Miss
Damage = 0
IsCritical = false
```

とする。

## 26. ダメージ計算の責務分離

通常攻撃処理とダメージ計算処理は概念上分離可能とする。

```text
Attack
    ↓
PhysicalDamageCalculation
```

ダメージ計算は、

```text
攻撃力
守備力
防御状態
会心状態
```

を入力としてダメージ量を返す。

HPを直接変更しない。

## 27. ダメージ計算概念

概念上、以下のような入力を想定する。

```text
PhysicalDamageInput
 ├ Attack
 ├ Defense
 ├ IsDefending
 └ IsCritical
```

結果として、

```text
Damage
```

を返す。

## 28. 通常攻撃時

```text
IsDefending = false
IsCritical = false
```

の場合、

```text
Attack / 2 - Defense / 4
```

を使用する。

## 29. 防御時

```text
IsDefending = true
IsCritical = false
```

の場合、

```text
Attack / 4 / 2 - Defense / 4
```

を使用する。

## 30. 会心時

```text
IsCritical = true
```

の場合、防御状態および守備力を無視する。

会心用ダメージ計算式については未確定とする。

## 31. C#概念モデル

通常攻撃を表す概念として以下を想定する。

```csharp
public sealed class Attack
{
    public AttackResult Execute(
        BattleParticipant attacker,
        BattleParticipant target);
}
```

ただし、具体的なクラス名や配置については実装時のドメイン構成に応じて決定する。

## 32. ダメージ計算概念モデル

```csharp
public interface IPhysicalDamageCalculator
{
    int Calculate(
        int attack,
        int defense,
        bool isDefending,
        bool isCritical);
}
```

具体的なインターフェース化の必要性については実装時に判断する。

単純な純粋関数として実装してもよい。

## 33. 攻撃の不変条件

通常攻撃処理では以下を保証する。

```text
対象は1体のみ
```

```text
ダメージは0以上
```

```text
ミス時のダメージは0
```

```text
死亡対象へダメージを与えない
```

```text
会心時には守備力を適用しない
```

```text
会心時には防御状態を適用しない
```

```text
攻撃結果と実際に適用したダメージ量を一致させる
```

## 34. 禁止事項

以下の処理を通常攻撃内部では行わない。

```text
ターンを進める
```

```text
次の行動者を決める
```

```text
戦闘の勝敗を決める
```

```text
装備変更を行う
```

```text
魔法ダメージを計算する
```

```text
死亡した対象を自動的に別対象へ変更する
```

## 35. テスト観点

### 通常命中

通常攻撃が命中する。

正しい攻撃力・守備力でダメージが算出される。

算出されたダメージだけHPが減少する。

### 命中判定

乱数0.0でミスとなる。

乱数0.05でミスとなる。

乱数0.1でミスとなる。

乱数0.1001で命中となる。

### ダメージ計算

攻撃力 / 2 - 守備力 / 4 で計算される。

除算結果の小数部分が切り捨てられる。

計算結果が負数の場合は0となる。

### 防御

防御状態の場合、防御用計算式が利用される。

防御していない場合は通常式になる。

防御行動実行前の対象には防御効果が適用されない。

### 死亡対象

対象が攻撃前に死亡していた場合は攻撃失敗となる。

別の対象へ自動変更されない。

ダメージは発生しない。

行動は消費される。

### 会心

会心の場合、守備力を無視する。

会心の場合、防御状態を無視する。

ミス時には会心判定を行わない。

会心は次の条件下で計算される。

こうげき　を選択時、乱数による判定。（これはミスの計算と同じ）
0.95-1.0 の値が出たときに会心となる。

### HP

残りHPを超えるダメージでもHPが0未満にならない。

HP0になった対象が死亡状態になる。

## 36. 他設計との境界

通常攻撃は以下の設計と連携する。

```text
Turn
 ↓
Attack
 ↓
BattleParticipant
```

Turnは攻撃を実行するタイミングを決定する。

Attackは命中判定とダメージ決定を行う。

BattleParticipantはダメージを受け、自身のHPと死亡状態を管理する。

また、

```text
Equipment
 ↓
BattleParticipant
 ↓
Attack
```

という関係とし、AttackがEquipmentを直接参照しない。

## 38. 未確定事項

攻撃について残る未確定事項は以下とする。

```text

```

```text
会心の一撃のダメージ計算式
```
