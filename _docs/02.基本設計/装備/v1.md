# 装備Value Object 詳細設計書

## 1. 目的

本設計書は、戦闘参加者が装備する武器、防具、アクセサリーをValue Objectとして実装するための詳細仕様を定義する。

装備は個体識別を必要としないためIDを持たない。

装備の同一性は、装備を構成する値によって判定する。

## 2. 対象範囲

本設計の対象は以下とする。

- 武器
- 防具
- アクセサリー
- 装備による能力値補正
- 装備の生成条件
- 装備の同値判定

以下は本設計の対象外とする。

- 装備変更処理
- 装備可能条件
- 職業による装備制限
- アイテム所持数
- 装備品の売買
- 装備品の取得
- 装備による特殊効果
- 状態異常耐性
- 装備による最終能力値の計算

## 3. 設計方針

装備はValue Objectとして扱う。

Value Objectであるため、以下の性質を持つ。

### IDを持たない

装備には一意な識別子を持たせない。

同じ値を持つ装備は同じものとして扱う。

### 不変とする

生成後に装備内部の値を変更しない。

攻撃力補正などを変更する場合は、既存の装備を変更するのではなく、新しい装備を生成する。

### 値によって同値判定する

名前を含め、装備を構成するすべての値が一致した場合のみ同値とする。

## 4. 装備種別

装備種別として以下を定義する。

```text
Weapon
Armor
Accessory
```

それぞれ以下を意味する。

| 種別 | 意味 |
|---|---|
| Weapon | 武器 |
| Armor | 防具 |
| Accessory | アクセサリー |

装備種別は必須値とする。

## 5. 装備が保持する値

装備は以下の値を保持する。

| 項目 | 型 | 必須 | 内容 |
|---|---|---:|---|
| Name | string | 必須 | 装備名称 |
| Type | EquipmentType | 必須 | 装備種別 |
| MaxHpModifier | int | 必須 | 最大HP補正 |
| MaxMpModifier | int | 必須 | 最大MP補正 |
| AttackModifier | int | 必須 | 攻撃力補正 |
| DefenseModifier | int | 必須 | 守備力補正 |
| AgilityModifier | int | 必須 | すばやさ補正 |

能力補正を行わない項目には0を設定する。

## 6. 装備名称

### 6.1 Name

装備名称を表す。

例：

```text
はがねのつるぎ
鉄のよろい
ちからのゆびわ
```

### 6.2 制約

以下の値は許可しない。

```text
null
空文字
空白文字のみ
```

有効な例：

```text
はがねのつるぎ
```

無効な例：

```text
""
"   "
```

### 6.3 同値判定

Nameは装備の値の一部として扱う。

そのため、能力補正がすべて同じでも名前が異なれば別の装備とする。

例：

```text
鉄の剣
攻撃力 +10
```

と、

```text
兵士の剣
攻撃力 +10
```

は異なるValue Objectとする。

## 7. 能力補正

装備は以下の能力値を補正できる。

### 7.1 最大HP補正

`MaxHpModifier`

戦闘参加者の最大HPへ加算する値を表す。

例：

```text
+20
0
-10
```

### 7.2 最大MP補正

`MaxMpModifier`

戦闘参加者の最大MPへ加算する値を表す。

### 7.3 攻撃力補正

`AttackModifier`

戦闘参加者の攻撃力へ加算する値を表す。

### 7.4 守備力補正

`DefenseModifier`

戦闘参加者の守備力へ加算する値を表す。

### 7.5 すばやさ補正

`AgilityModifier`

戦闘参加者のすばやさへ加算する値を表す。

## 8. 補正値の仕様

能力補正値には以下を許可する。

```text
正数
0
負数
```

正数の場合は能力値を増加させる。

負数の場合は能力値を減少させる。

0の場合はその能力値に影響を与えない。

例：

```text
重い鎧

最大HP       +0
最大MP       +0
攻撃力       +0
守備力      +40
すばやさ    -10
```

装備VO自身は、補正後の能力値が0未満になるかどうかを判定しない。

最終能力値の保証は戦闘参加者側の責務とする。

## 9. 武器

武器は`EquipmentType.Weapon`として表現する。

武器は主に攻撃力を補正することを想定する。

ただし、補正可能な能力値を攻撃力だけには限定しない。

例：

```text
はがねのつるぎ

種別          Weapon
最大HP        +0
最大MP        +0
攻撃力       +20
守備力        +0
すばやさ      +0
```

以下のような武器も許可する。

```text
はやぶさの剣

種別          Weapon
最大HP        +0
最大MP        +0
攻撃力       +10
守備力        +0
すばやさ      +5
```

## 10. 防具

防具は`EquipmentType.Armor`として表現する。

主に守備力を補正することを想定する。

ただし、守備力以外の補正も許可する。

例：

```text
鉄のよろい

種別          Armor
最大HP        +0
最大MP        +0
攻撃力        +0
守備力       +25
すばやさ      -3
```

## 11. アクセサリー

アクセサリーは`EquipmentType.Accessory`として表現する。

アクセサリーは特定の能力値に限定せず、任意の能力補正を持つことができる。

例：

```text
ちからのゆびわ

種別          Accessory
最大HP        +0
最大MP        +0
攻撃力        +5
守備力        +0
すばやさ      +0
```

別の例：

```text
ほしふるうでわ

種別          Accessory
最大HP        +0
最大MP        +0
攻撃力        +0
守備力        +0
すばやさ     +30
```

## 12. Value Object構成

装備は概念上、以下の構造とする。

```text
Equipment
 ├ Name
 ├ Type
 └ Modifier
      ├ MaxHp
      ├ MaxMp
      ├ Attack
      ├ Defense
      └ Agility
```

能力補正については、装備とは別のValue Objectとして扱う。

## 13. EquipmentModifier

能力補正値を表現するValue Objectとして`EquipmentModifier`を定義する。

保持する値は以下とする。

```text
MaxHp
MaxMp
Attack
Defense
Agility
```

すべて整数値とする。

### 同値判定

すべての補正値が一致した場合に同値とする。

例：

```text
Modifier A
HP      0
MP      0
Attack 20
Defense 0
Agility 0
```

と、

```text
Modifier B
HP      0
MP      0
Attack 20
Defense 0
Agility 0
```

は同値とする。

## 14. Equipment

装備全体を表すValue Objectとする。

概念上の構成は以下とする。

```csharp
Equipment
{
    Name
    Type
    Modifier
}
```

Equipment自身も不変とする。

## 15. 同値判定

Equipmentは以下のすべてが一致した場合に同値とする。

```text
Name
Type
Modifier.MaxHp
Modifier.MaxMp
Modifier.Attack
Modifier.Defense
Modifier.Agility
```

### 同値となる例

```text
装備A

Name      はがねのつるぎ
Type      Weapon
Attack    +20
Defense   0
Agility   0
MaxHp     0
MaxMp     0
```

```text
装備B

Name      はがねのつるぎ
Type      Weapon
Attack    +20
Defense   0
Agility   0
MaxHp     0
MaxMp     0
```

この2つは同値とする。

### 同値とならない例1

```text
装備A
はがねのつるぎ
攻撃力 +20
```

```text
装備B
はがねのつるぎ
攻撃力 +21
```

名前が同じでも補正値が異なるため、別のValue Objectとする。

### 同値とならない例2

```text
鉄の剣
攻撃力 +10
```

```text
兵士の剣
攻撃力 +10
```

能力補正が同じでも名前が異なるため、別のValue Objectとする。

## 16. C#実装モデル

実装時には、Value Objectの不変性と値による同値判定を表現できる構造とする。

概念的には以下とする。

```csharp
public enum EquipmentType
{
    Weapon,
    Armor,
    Accessory
}
```

```csharp
public sealed record EquipmentModifier(
    int MaxHp,
    int MaxMp,
    int Attack,
    int Defense,
    int Agility
);
```

```csharp
public sealed record Equipment
{
    public string Name { get; }
    public EquipmentType Type { get; }
    public EquipmentModifier Modifier { get; }

    public Equipment(
        string name,
        EquipmentType type,
        EquipmentModifier modifier)
    {
        // Validation

        Name = name;
        Type = type;
        Modifier = modifier;
    }
}
```

実際の例外型や生成方式についてはプロジェクト共通設計に従う。

## 17. 生成時バリデーション

Equipment生成時には以下を検証する。

### Name

以下の場合は生成を許可しない。

```text
null
空文字
空白のみ
```

### Type

定義されている装備種別のみ許可する。

### Modifier

Modifierが存在しない状態を許可しない。

補正がない装備についても、すべて0のEquipmentModifierを指定する。

例：

```text
MaxHp   0
MaxMp   0
Attack  0
Defense 0
Agility 0
```

## 18. 不変条件

Equipmentは常に以下を満たさなければならない。

```text
Nameが有効である
Typeが有効である
Modifierが存在する
生成後に値が変更されない
```

EquipmentModifierは常に以下を満たす。

```text
すべての補正値が整数である
生成後に値が変更されない
```

補正値について正数・0・負数のすべてを許可する。

## 19. 装備なし

装備なしはEquipmentの一種として表現しない。

つまり、

```text
名前: 装備なし
能力値: 0
```

というダミー装備は作成しない。

武器、防具、アクセサリーを装備していない状態については、装備を保持する側で「装備が存在しない」として表現する。

具体的な表現方法については戦闘参加者の詳細設計で定義する。

## 20. 戦闘参加者との責務分離

Equipmentは、自身が持つ能力補正値だけを管理する。

Equipment自身は以下を行わない。

```text
戦闘参加者の攻撃力を計算する
戦闘参加者のHPを書き換える
最大HPを超えていないか確認する
装備可能か判断する
装備を変更する
```

これらはEquipmentの責務としない。

Equipmentが提供する情報は、

```text
「この装備によって、どの能力値がどれだけ変化するか」
```

までとする。

## 21. 能力補正の適用例

以下の戦闘参加者を想定する。

```text
最大HP      100
最大MP       30
攻撃力       50
守備力       30
すばやさ     20
```

装備：

```text
はがねのつるぎ
攻撃力 +20
```

```text
鉄のよろい
守備力 +25
すばやさ -3
```

```text
ちからのゆびわ
攻撃力 +5
```

装備補正の合計は、

```text
最大HP       0
最大MP       0
攻撃力     +25
守備力     +25
すばやさ    -3
```

となる。

最終能力値は戦闘参加者側で、

```text
最大HP      100
最大MP       30
攻撃力       75
守備力       55
すばやさ     17
```

として算出する。

この計算結果をEquipment自身は保持しない。

## 22. テスト観点

Equipmentについて最低限以下を確認する。

### 正常系

有効な名前で生成できる。

Weaponを生成できる。

Armorを生成できる。

Accessoryを生成できる。

正の補正値を保持できる。

0の補正値を保持できる。

負の補正値を保持できる。

### 異常系

Nameがnullの場合、生成できない。

Nameが空文字の場合、生成できない。

Nameが空白のみの場合、生成できない。

Modifierが存在しない場合、生成できない。

### 同値判定

すべての値が同じEquipmentは同値となる。

名前だけ異なるEquipmentは非同値となる。

装備種別だけ異なるEquipmentは非同値となる。

補正値が1つでも異なるEquipmentは非同値となる。

同じ名前でも攻撃力補正が異なる場合は非同値となる。

## 23. 設計上の確定事項

装備について以下を確定事項とする。

```text
装備はValue Objectとする
装備はIDを持たない
装備はImmutableとする
名前は値の一部とする
名前を同値判定に含める
能力補正を同値判定に含める
装備種別を同値判定に含める
補正値には負数を許可する
武器・防具・アクセサリーは同じ能力補正構造を利用できる
特殊効果は現時点では扱わない
```

## 24. 次の設計との境界

本設計では装備そのものの仕様までを定義した。

次に戦闘参加者を詳細設計する場合は、以下を戦闘参加者側で定義する。

```text
武器の保持
防具の保持
アクセサリーの保持
装備なしの表現
装備変更
装備補正の合算
最終攻撃力の算出
最終守備力の算出
最終すばやさの算出
最大HP補正
最大MP補正
装備解除によって現在HP/MPが最大値を超えた場合の補正
```

これらはEquipmentではなく、戦闘参加者側の責務として扱う。
